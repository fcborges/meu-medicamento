# Meu Medicamento

Aplicativo Android nativo para controle familiar de medicamentos.

## Funcionalidades planejadas
- Cadastro de Fátima, Matteo e Lorenzo
- Cadastro de medicamentos, doses e duração do tratamento
- Grade diária com horários e confirmação de administração
- Registro do horário real e histórico
- Notificações locais, widget, backup e exportação

## Estado
Repositório inicializado. O código-fonte completo ainda precisa ser enviado e compilado antes de gerar um APK utilizável.

Não use este aplicativo como substituto de orientações médicas.
